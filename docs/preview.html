一键安装

支持 Debian / Ubuntu 服务器。准备解析到服务器的邮件主机名，例如 mail.example.com。

curl -fsSL https://raw.githubusercontent.com/logdns/imyemail/main/install.sh | sudo bash

脚本会自动完成：下载 Rust 管理器并校验 SHA-256，安装 Docker Engine 与 Compose v2。

超长链接不再错位：https://raw.githubusercontent.com/logdns/imyemail/main/install.sh?token=abcdefghijklmnopqrstuvwxyz1234567890veryveryverylongstring，随便点。
